## Class imbalance

**The classes are imbalanced.** `early_blight` has 1000 images and `healthy` has 152, a ratio of 6.58:1. The smallest class is 7.1% of the data.

Why it matters here: a model can score well on overall accuracy while being unreliable on the small class, and `healthy` is the class that says "do nothing". So:

- report per-class precision and recall, and a confusion matrix, not just accuracy;
- use class weights or balanced sampling during training;
- treat macro-averaged F1 as the headline number in Chapter 5.

## Source, citation and licence

- Dataset: PlantVillage, the standard leaf-disease collection (TFDS `plant_village`: 54,303 images, 38 classes). Only the 3 potato classes are exported here.
- Data record: https://data.mendeley.com/datasets/tywbtsjrjv/1 (DOI 10.17632/tywbtsjrjv.1).
- **Licence: CC0 1.0 (public domain dedication)**, as stated on that record.
- Export route: Mendeley archive plantvillage_mendeley.zip. Mendeley refuses TFDS's downloader with HTTP 403 while serving the same file to a browser, so the archive is downloaded once with curl and exported from directly; the data is identical.
- The archive holds both an augmented and a non-augmented copy. Only the non-augmented copy is used: the augmented images are rotations and colour shifts of the originals, which would put near-duplicates on both sides of the split.
- The three potato class names come from the dataset's own label names (`Potato___Early_blight`, `Potato___Late_blight`, `Potato___healthy`) and are validated at export time rather than hard-coded, so a change in the dataset stops the export instead of mislabelling it.

## Known limitation

PlantVillage images are single leaves photographed against a plain background in controlled conditions. The farmer will photograph leaves in a field, in daylight, against soil and other foliage. Accuracy on PlantVillage test data is therefore an upper bound, not an estimate of field performance; the field images collected under `data/field_images/` are what make a fair second evaluation possible.
